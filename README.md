# 🍰 Dessert Shopping Cart
A simple, interactive shopping cart web app built with HTML, CSS, and JavaScript. This project demonstrates dynamic DOM manipulation, object‑oriented programming, and basic e‑commerce logic such as adding items, calculating totals, and applying taxes.

## ✨ Features
- Display a catalog of desserts with name, price, and category.
- Add items to the cart with quantity tracking.
- Automatic subtotal, tax, and total calculation.
- Show/Hide cart functionality.
- Clear cart with confirmation prompt.
- Organized with ES6 classes (Dessert and ShoppingCart).

## 📂 Project Structure
index.html        # Main page  
style.css         # Styling for layout and dessert cards  
script.js         # JavaScript logic (cart + products)
